# Preview dashboard design

A compact LAN dashboard for finding, opening, and sharing active previews.
Direction: quiet, utilitarian, legible. The visual reference is an operations
ledger: one framed list with ruled rows, not a wall of cards.

- Monospace headings and endpoint values; humanist sans for labels and help.
- Dark pine background, a lighter ledger surface, and lime for links, focus,
  and the selected filter. The top rule anchors the page.
- An 8 px spacing unit, square borders, no shadows or animation.
- Scope filters use links with an explicit current state. Rows stack on narrow
  screens. External credentials start collapsed in native disclosure controls.
- Empty and populated states are covered by template tests; no client scripts,
  remote fonts, or third-party assets.
